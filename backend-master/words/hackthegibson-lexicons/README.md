# Hack the Gibson — Lexicon

Custom lexicon for the **Hack the Gibson** cyberpunk theme, drawn entirely from the 1995 movie *Hackers*.

## Files

| File | Description |
|---|---|
| `adjectives.txt` | One adjective per line |
| `compound adjectives.txt` | `# Prefix` section then `# Base` section |
| `compound nouns.txt` | `# Prefix` section then `# Base` section |
| `generic medals.txt` | Achievement titles |
| `instruction patterns.txt` | Uses `%@` for control name, `%d` for number |
| `intermission text.txt` | Flavor text between rounds |
| `nouns.txt` | One noun per line |
| `on-off verbs.txt` | `ON VERB, OFF VERB` per line |
| `phrases.txt` | `BUTTON LABEL, PANEL LABEL` per line |
| `verbs.txt` | One verb per line |

## Theme

Sectors → Network Nodes. Hyperspace → Proxy Bounces. Asteroids → FBI Traces. Black Holes → Virus Attacks.

**Hack the Planet.**
